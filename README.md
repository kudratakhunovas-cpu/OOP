# Health Parameter Tracker

## Student
Samina Kudratakhunova

## Description
This project tracks health parameters such as weight, blood pressure, and exercise.

## Objectives
- Track health data
- Manage records using CRUD
- Store data in files

## Requirements
1. CRUD operations ✔
2. CLI ✔
3. Validation ✔
4. File storage ✔
5. Modular design ✔
6. Documentation ✔
7. Error handling ✔
8. Encapsulation ✔
9. Inheritance ✔
10. Polymorphism ✔

## How it works
- User adds health data
- Data is saved in CSV file
- User can edit/delete records
